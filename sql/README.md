# SQL Notes

The repository stores the main datasets as CSV files so they are easy to inspect.

The SQL folder contains:

- `01_schema.sql` - SQLite-compatible table definitions
- `02_market_analysis_queries.sql` - example market-intelligence queries

The queries answer practical questions such as:

- Which markets are growing fastest?
- Which countries combine size and growth?
- Which competitors have the strongest regional position?
- Which customer segments are most attractive?
- What is the Base-case revenue potential in the priority markets?

I kept the SQL readable because the purpose of the project is to show how I would analyse business questions as a student / junior analyst, not to make the queries complicated for the sake of it.
